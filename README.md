\# 张标 · 大数据方向个人作品集



一个基于原生 HTML / CSS / JavaScript 构建的个人作品集网站，展示数据科学与大数据技术方向的个人介绍、项目作品、技能栈与联系方式。无任何前端框架与第三方 UI 库依赖，兼容桌面端与移动端。



\## ✨ 功能特性



\- \*\*响应式布局\*\*：桌面端侧栏导航 + 移动端顶栏抽屉菜单，自适应不同屏幕尺寸

\- \*\*深浅色主题切换\*\*：导航栏右侧一键切换，使用 localStorage 持久化用户偏好

\- \*\*项目分类筛选\*\*：按"大数据算法分析 / 用户行为挖掘 / 数据建模 / AI辅助开发"分类筛选，筛选按钮根据数据自动生成

\- \*\*锚点导航 + Scrollspy\*\*：滚动时自动高亮当前章节，点击平滑跳转

\- \*\*滚动进入动效\*\*：章节内容滚动到可视区域时淡入展示，尊重 `prefers-reduced-motion`

\- \*\*数字滚动动画\*\*：统计数据进入视口时执行缓动累加

\- \*\*Canvas 粒子背景\*\*：动态数据粒子背景，颜色随主题同步变化，标签页隐藏时自动暂停以节能

\- \*\*无障碍支持\*\*：语义化标签、ARIA 属性、键盘可达



\## 🛠 技术栈



| 类别 | 技术 |

\## 🧩 主要功能说明



\### 1. 项目筛选

项目数据位于 `js/projects-data.js` 的 `PROJECTS` 数组中，每个项目通过 `category` 字段标记分类。筛选按钮由 `main.js` 根据数据中出现的分类自动生成，\*\*新增项目只需追加一个对象\*\*，筛选按钮会同步更新，无需改其他代码。



\### 2. 主题切换

\- 默认深色主题，浅色主题通过 `html\[data-theme='light']` 覆盖 CSS 变量实现

\- 所有颜色（背景、文字、边框、Canvas 粒子）均使用 CSS 变量驱动，切换时整体同步

\- 用户偏好通过 `localStorage` 的 `portfolio-theme` 键持久化，刷新后保持



\### 3. 数据粒子背景

`main.js` 中的 `initCanvas()` 根据屏幕面积自适应粒子数量（最多 90 个），粒子颜色从 CSS 变量 `--particle-dot-rgb` 与 `--particle-link-rgb` 读取，因此切换主题时粒子背景颜色自动跟随。



\## 📝 开发约定



本项目遵循 `.trae/rules/project\_rules.md` 中的开发规则，核心要点：



1\. 原生 HTML / CSS / JS 开发，不使用 React / Vue 等前端框架

2\. 不引入第三方 UI 组件库

3\. HTML / CSS / JS 分别放在对应文件中

4\. 保持现有页面结构，不随意修改与当前任务无关的功能

5\. 修改前先阅读现有代码，优先复用已有结构和逻辑

6\. 兼容桌面端和移动端

7\. 新增功能后须在浏览器中验证

8\. 不破坏已有功能，特别是项目类别筛选功能
